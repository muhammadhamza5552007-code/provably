## Overview

Provably is a developer-focused AI platform designed to help developers **understand, analyze, and verify AI-generated code** before trusting it.

It bridges the gap between **AI-generated software and human technical confidence**.

## Core Features

* 🧠 AI-powered code understanding
* 🔍 Repository-aware code analysis
* 🛡️ Risk and security analysis
* 🧩 Structural & dependency analysis
* 🧪 Verification-oriented workflows
* 🎯 Developer comprehension evaluation
* 📊 Knowledge-gap identification

```bash
git clone <repository-url>
cd provably
npm install
npm run dev
```

Create a `.env` file and configure the required environment variables.
